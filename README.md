# ANOS — Agentic Native Operating System

ANOS is a general-purpose **Agentic Native Operating System** in which autonomous agency is a fundamental execution paradigm.

ANOS natively supports both conventional deterministic programs and autonomous computational agents. Agents are treated as first-class computational principals across execution, identity, delegation, security, scheduling, memory, communication, resource management, lifecycle, observability, and accountability.

Agentic functionality is not an application or optional orchestration layer added on top of the operating system. It is part of the operating system's native computational model.

## Core premise

> Autonomous agency is a fundamental execution paradigm of ANOS.

> Conventional deterministic applications remain native first-class workloads.

## Why ANOS exists

Traditional operating systems primarily model computation through users, processes, threads, files, sockets, permissions, and services. Autonomous software agents introduce a different kind of computational actor: one that pursues goals, selects actions, uses tools, maintains state, delegates work, consumes heterogeneous resources, and operates under authority delegated by a human, organization, system principal, or another agent.

ANOS exists to make that actor native to the operating system rather than forcing it to masquerade as an ordinary process, service, or human user.
