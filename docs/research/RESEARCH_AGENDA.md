# ANOS Research Agenda

Initial research areas:

1. First-class agent identity and Agent Control Blocks.
2. Capability-based delegated authority.
3. Agent-aware but deterministic security enforcement.
4. Hierarchical agent/process resource accounting.
5. Agent lifecycle and checkpoint/restore semantics.
6. Persistent and protected agent memory.
7. Native agent-to-agent communication.
8. Delegation provenance and accountability.
9. Agent scheduling across CPU/GPU/model/token/cost resources.
10. Human approval and dynamic capability escalation.
11. Live revocation of agent authority.
12. Compatibility with conventional POSIX/process workloads.
13. Compiler/runtime integration for agentic optimization and execution.
14. Kernel-versus-user-space placement of native agent primitives.
