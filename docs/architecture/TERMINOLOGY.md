# ANOS Terminology

## ANOS
**Agentic Native Operating System.** A general-purpose operating system where autonomous agency is a fundamental execution paradigm.

## Agent
A persistent or durable, goal-directed computational principal capable of autonomously selecting actions within explicitly delegated authority and resource constraints.

## Principal
An entity recognized by ANOS as capable of owning or delegating authority. Initial categories include human principals, system principals, and agent principals.

## AID
Working term for **Agent Identifier**: a native identity assigned to an ANOS agent.

## Agent Control Block (ACB)
Working architectural term for the native system state associated with an agent. Expected concerns include identity, principal, parent/child relationships, goal state, capabilities, resources, lifecycle state, memory references, and audit/provenance state.

## Delegation
The explicit transfer of a bounded subset of authority from one principal to another agent principal.

## Capability
A machine-enforceable authorization to perform a class of operation on a resource or service.

## Goal
The semantic objective an agent is pursuing. Goals are not themselves equivalent to enforceable security policy.

## Policy
Deterministic, machine-enforceable rules governing what operations an agent may perform.

## Autonomous agency
The ability of a computational principal to choose actions in pursuit of a goal without requiring a human to direct each individual step.
